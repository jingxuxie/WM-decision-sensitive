# Research-draft style

The local `iclr2027_conference.sty` is an explicitly modified research-draft copy
of the formatting macros read from the official ICLR/Master-Template repository,
`iclr2027/iclr2027_conference.sty` (original Git blob
`f61ad7efce0855557694078c0945e6c33feb8236`, accessed September 15, 2026).

The page dimensions, type sizes, title spacing, paragraph and section formatting
are retained. Unused review-ruler code and comments are omitted. The title/author
block and running header say "research draft", not "under review" or "published".
No conference submission has been made. Bibliography entries are maintained
explicitly in the TeX source rather than generated by the official BST.

Before submission replace this local file with the untouched official style,
restore the official anonymous review mode, review all bibliography formatting,
and compile/check the page limit again. Do not present this draft as already
compliant with every final venue requirement. No font files are distributed.

Official source:
https://github.com/ICLR/Master-Template/tree/master/iclr2027
